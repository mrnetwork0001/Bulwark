The only track
Build an agent that works (literally)
Build an AI agent, or a team of agents, that completes a substantial task from start to finish.
Give it a goal, tools and an environment; let each result guide its next action. All projects compete for the same prizes.

Focus areas
Planning
Break a goal into actionable steps.

Tool use
Choose tools, supply inputs and handle responses.

State
Retain state across steps, runs and failures.

Context
Bring in relevant information; leave out the rest.

Execution
Keep long tasks running to completion.

Recovery
Handle failures and unexpected results.

Verification
Check that results are correct.

Iteration
Use each result to choose the next step.

See example tasks
These examples show the size of task we have in mind. They aren't separate tracks, and you don't have to build one of them.

Fix a GitHub issue
An agent investigates a GitHub issue, writes and tests a fix, and proposes the fix.
Answer a research question with sources
An agent splits a question into smaller questions and gathers evidence for each one. When sources disagree, the agent works out which source to trust and writes an answer with citations.
Watch a running system
An agent watches a running system for unusual behavior. When the agent finds a problem, it looks for the cause and takes an action to fix it.
Several agents working together
Several worker agents each solve part of a task on their own. A coordinator agent then combines their results and settles any disagreements.
Work while things change
An agent works on a long task while the environment it works in keeps changing.

Judging criteria
Judges score each project in five categories. Each category is scored out of 100, and the categories are weighted as shown to give a final score out of 100.

The agent
How well the agent, or the system of agents, handles a substantial task from start to finish.

30%
Use of neatlogs, Entire and cfo.ai
How effectively you used neatlogs, Entire and cfo.ai to build, improve and plan a business around the agent.

25%
Demo video
How clearly the demo video explains the agent and your use of neatlogs, Entire and cfo.ai.

20%
Building in public
How you shared your project with other people while you built it.

15%
Usefulness and originality
Whether the agent solves a problem that people have, in a new way.

10%
