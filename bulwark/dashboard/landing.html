Attack. Observe. Fix. Prove.

Unit tests check that your agent works. Bulwark checks that it keeps working when the world breaks.

Attack

Reads your agent's code, finds unguarded tool calls, and injects faults between the agent and its services, in a sandbox.

Observe

Runs every attack many times and checks your rules, written in plain English, against what really happened in the ledger.

Fix

A fixer agent writes the patch: timeouts, idempotency keys, validation, step budgets. Each attempt is checkpointed, and a failed fix is rolled back.

Prove

A separate Judge agent re-runs every attack on fresh seeds, tests the improvement for significance, checks nothing else regressed, and writes the PR with the evidence.

Built to be trusted, not just impressive

The fixer never grades its own work

Red, Blue and Judge agents attack, fix and verify separately, so a fix only counts when an independent run confirms it.

Honest statistics

Pass rates come with 95% confidence intervals. A lucky streak is never reported as a fix.

Safe by default

Sandbox-only targets, a budget cap on every run, and a human merges every PR. Bulwark never pushes to main.
