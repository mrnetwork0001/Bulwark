## Assumptions (not measured)

- **Compute rate**: $0.1/hour, a 2 vCPU / 4 GB on-demand cloud VM running the loop (override with `BULWARK_COMPUTE_USD_PER_HOUR`).
- **LLM prices**: 0G Compute Router list prices from its public `/v1/models` endpoint (USD per token), Anthropic first-party list prices for direct calls. No volume discounts.
- **Simulated target brain**: unless noted, trials run RefundBot on the deterministic simulated brain, so trials cost compute only. The real-LLM column below prices the same suite with a real model behind the agent.
- **Real-LLM suite size**: 140 real-model trials per run (one Red scorecard: baseline + 6 faults × 20 trials). The Judge's thousands of trials stay simulated.
- **Real-LLM model**: priced at the most expensive model on the leaderboard (`claude-sonnet-5`, $0.017/trial), so the margin is a floor. Cheaper models raise it.
- **Plans, prices and run cadence** below are proposals for the business plan, not market data.
- **Not included**: hosting the dashboard, storage, support, sales, payment fees, neatlogs/Entire subscriptions.

## Pricing scenarios (assumed prices × measured costs)

| Plan | Price / agent / month | Loop runs / month | COGS (simulated target) | Gross margin | COGS (real-LLM target, claude-sonnet-5) | Gross margin |
|---|---|---|---|---|---|---|
| Starter | $49 | 4 (weekly loop run) | $0.253 | 99.5% | $9.86 | 79.9% |
| Team | $199 | 30 (daily loop run) | $1.90 | 99.0% | $73.94 | 62.8% |
| Enterprise | $799 | 120 (~4 runs/day, one per PR) | $7.60 | 99.0% | $295.76 | 63.0% |

_COGS = runs per month × measured cost per run (+ runs × real-LLM trials per run × measured real-LLM cost per trial). Gross margin = (price − COGS) / price._

**Market assumptions (not measured):**

- **Agents per company** (by headcount): 1-10: 1, 11-50: 2, 51-200: 3, 201-1000: 5, 1001-5000: 10, 5001+: 20. A guess at production agents per buyer, not measured.
- **Plan by company size**: 1-10: Starter, 11-50: Starter, 51-200: Team, 201-1000: Team, 1001-5000: Enterprise, 5001+: Enterprise. Prices per agent per month from the economics module (Starter $49, Team $199, Enterprise $799).
- **Adoption** (share of SAM companies paying at year end): Year 1 0.1%, Year 2 0.3%, Year 3 1%. SOM = Year 3. Deliberately conservative.
- **TAM** = companies tagged AI by Crustdata, or with agent/LLM specialities. **SAM** = the agent/LLM-speciality subset (companies that build or ship agents). Companies with no headcount on record are not in any band, so they are left out.
- Every company in a band is priced at that band's plan, with all its agents covered. ARR = companies × agents × price × 12.

## Reproduce

```bash
npm run fix -- --fixer auto          # one loop run (LLM fixer if a key is set), writes .bulwark/runs/<id>/summary.json
npm run leaderboard                  # optional: measures real-LLM cost per trial
npm run market                       # optional: Crustdata market sizing (cached in market-data.json)
npm run economics                    # rewrites this file and unit-economics.csv
```
